# Dr. Ambairam Muthu Sivakrishna — Academic & Research Website

A responsive GitHub Pages website designed for an academic/research profile.

## Academic order

1. Home / academic identity
2. Academic profile
3. Education
4. Research
5. Publications
6. Achievements
7. Teaching
8. Student research opportunities
9. Academic experience & leadership
10. Professional service
11. Contact

## Visual system

The default palette is **White + Royal Blue**. The header also provides **White + Maroon** and **White + Teal/Indigo** alternatives. Theme choice is saved in the browser.

Official institutional logos are used for Alliance University, NIT Tiruchirappalli and IIIT Tiruchirappalli. Selected academic photographs are stored in `assets/` and used for the hero/profile, teaching and achievement sections.

## Deploy on GitHub Pages

Upload all files and the complete `assets/` folder to the root of the `amskrishna.github.io` repository and push to `main`. No npm/build step is required.

## Editing content

Most profile content is stored in `data.js`. `admin.html` can still be used for the existing data-driven editing workflow. Images and institutional logos can be replaced inside `assets/` while keeping the same filenames.
