Content editing dashboard

Edit your academic website

Use Pages CMS to edit website content through forms. Saving a change commits it to your website repository. GitHub Pages then publishes the updated version.

Open Pages CMS

One-time connection

  1. Upload this website package to the root of amskrishna/amskrishna.github.io. Include .pages.yml, the content folder and all assets.
  2. Open Pages CMS and sign in with GitHub.
  3. Install its GitHub App for the amskrishna.github.io repository. Select only this repository when granting access.
  4. Open the repository and select the branch used by GitHub Pages, normally main.

Everyday updates

Select a section, edit its fields, and save. Add publications, news or courses using the repeatable entries. Use Profile & contact to update the biography, contact details, profile photo, logo or CV.

After saving, allow the GitHub Pages deployment to finish, then refresh the public website. You do not need to open GitHub for routine content edits.

The dashboard becomes connected only after you authorize the repository. This page does not store passwords or provide an unsecured editor.
